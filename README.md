# Sip Atelier

A modern and responsive tea e-commerce frontend built with React and Vite. Sip Atelier provides a clean shopping experience with product browsing, cart management, wishlist, checkout, and order tracking.

## 🚀 Live Demo

[Visit Sip Atelier](https://peppy-vacherin-e9c793.netlify.app)

## 🛠️ Technologies

- React 18
- Vite
- React Router DOM
- Tailwind CSS
- Lucide React
- React Context API
- JavaScript

## ✨ Features

- Responsive tea e-commerce interface
- Product browsing and product details
- Shopping cart
- Wishlist
- Checkout flow
- Order confirmation
- Order tracking
- Login & registration pages
- Contact and About pages
- Responsive design for desktop and mobile

## 📦 Dependencies

### Main Dependencies

- `react` — UI development
- `react-dom` — React DOM rendering
- `react-router-dom` — Client-side routing
- `lucide-react` — Icons

### Development Dependencies

- `vite`
- `tailwindcss`
- `postcss`
- `autoprefixer`
- `@vitejs/plugin-react`
