# 🍵 Sip Atelier

A premium, modern, and fully responsive tea e-commerce website built with
**React, Tailwind CSS, React Router, and Vite**.

Sip Atelier provides a complete online tea shopping experience where users
can explore tea products, search and filter products, view detailed product
information, manage their cart and wishlist, checkout, and track orders.

## 📖 Project Overview

**Sip Atelier** is a modern tea e-commerce frontend designed to provide
customers with a smooth and premium shopping experience.

The application includes product browsing, category-based shopping,
product details, cart management, wishlist functionality, checkout,
authentication pages, order confirmation, and order tracking.

The interface is designed to be fully responsive and optimized for
different screen sizes including mobile, tablet, and desktop.

# 🛠️ Tech Stack

### Frontend

- **React** — Building the user interface
- **React Router** — Client-side routing
- **Tailwind CSS** — Styling and responsive design
- **Vite** — Development server and build tool
- **Lucide React** — Interface icons

### State Management

- **React Context API**
- **Browser localStorage**
